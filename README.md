## Pre-requisites

### Usage of Git / GitLab

- [Git Guide](https://rogerdudler.github.io/git-guide/)
- [Learn Git Branching](https://learngitbranching.js.org)
- [Gitflow Workflow](https://www.atlassian.com/git/tutorials/comparing-workflows/gitflow-workflow)
- [Learn Git](https://docs.gitlab.com/ee/topics/git/)

### Documentation with Markdown

- [Markdown Guide](https://www.markdownguide.org/)
- [Markdown Cheatsheet](https://www.markdownguide.org/cheat-sheet/)

### Cloud & Data Warehousing

- Basic understanding of cloud computing and cloud services.
- Familiarity with Google Cloud Platform (GCP) and its services, especially BigQuery.
- [How to Create a Free Tier Account on GCP](https://www.geeksforgeeks.org/how-to-create-a-free-tier-account-on-gcp/)

### SQL

- [SQL Tutorial](https://www.w3schools.com/sql/)
- [BigQuery SQL](https://www.youtube.com/watch?v=MH5M2Crn6Ag)

### Python & Required Libraries

- Make sure Python is installed on your computer. You can download and install Python from the official website: [Python Downloads](https://www.python.org/downloads/).
- Get familiar with the following Python libraries:
  - [Pandas](https://pandas.pydata.org/)
  - [NumPy](https://numpy.org/)
  - [Scikit-learn](https://scikit-learn.org/stable/)
- Get familiar with one of the following Python tools:
  - [Jupyter Notebook](https://jupyter.org/)
  - [Google Colab](https://colab.research.google.com/)
- Get familiar with one the following IDEs:
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [PyCharm](https://www.jetbrains.com/pycharm/)

### Visualisation Tools

You might want to get familiar with one the following Business Intelligence (BI) tools:

- [Google Data Studio](https://datastudio.google.com/)
- [Tableau](https://www.tableau.com/)
- [Power BI](https://powerbi.microsoft.com/)

Also get familiar with one of the following Python libraries:

- [Matplotlib](https://matplotlib.org/)
- [Seaborn](https://seaborn.pydata.org/)
- [Plotly](https://plotly.com/python/)
- [Bokeh](https://docs.bokeh.org/en/latest/index.html)

If you are interested in web-based visualisation, you might want to get familiar with the following JavaScript Libraries:

- [ECharts](https://echarts.apache.org/)
- [D3.js](https://d3js.org/)
